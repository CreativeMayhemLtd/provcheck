Cached license proof for CompressAI (neural-codec embed dependency).

Source:            compressai (PyPI), the learned-image-codec library
Upstream project:  https://github.com/InterDigitalInc/CompressAI
Classifier:        License :: OSI Approved :: BSD License  (PyPI package metadata)
Declared license:  "BSD 3-Clause Clear License"  (PyPI license field)
SPDX:              BSD-3-Clause-Clear
What uses it:      The BUSL-1.1 Backfire EMBED tool only (backfire/backfire.py,
                   the --codec-eot default). compressai.zoo bmshj2018_factorized
                   (quality 1 and 3) is the neural-codec fixed point the keyed
                   mark is optimized to survive; cheng2020 and mbt2018 are used
                   as VAE-attack test targets. NONE of this is compiled into or
                   linked with the Apache-2.0 provcheck verifier, and the free
                   reader never loads compressai.
What ships here:   NOTHING. compressai is a runtime dependency installed with
                   `pip install compressai>=1.2` (see backfire/setup_backfire.sh
                   and setup_backfire.ps1), and its pretrained weights are fetched
                   from the compressai model zoo at embed time. provcheck
                   redistributes neither the library nor the weights; this file is
                   a disclosure, not a redistribution notice.
Patent note:       The "Clear" variant grants NO patent rights (see the clause in
                   the terms below). InterDigital is a patent licensor and neural
                   codecs are a patent-dense field, so this dependency carries no
                   patent grant. Exposure is low for the non-redistributed,
                   embed-time, adversary-proxy use described above, but it is
                   recorded here rather than omitted.
Captured:          2026-09-30, from the upstream LICENSE and PyPI metadata
                   (compressai 1.2.8). The pretrained weights carry no separate
                   license file, so they are covered by the repository-wide terms
                   below, the same treatment applied to the TrustMark weights. The
                   verbatim BSD 3-Clause Clear terms follow.

# v1.4.1 feature-complete

Patch release. Adds the free, Apache-2.0 provcheck **browser extension** (Chrome and Chromium; Firefox
pending verification). No changes to the verifier, kit, GUI, wire format, or any watermark. Source-only
addition under `browser-extension/`.

## What ships
- `browser-extension/`: a Manifest V3 extension. Byte-scan C2PA presence and AI-generation markers on any
  fetchable media; read YouTube's own "Altered or synthetic content" AI self-disclosure from the page;
  filter the local render (blur or hide) by C2PA presence, AI presence, YouTube AI disclosure, or a
  keyword; caption blurred media with an "AI Generated Content Detected" banner; a hover provenance badge;
  and a right-click "Inspect C2PA provenance" panel. Local only, no telemetry, and it never modifies or
  re-uploads media. Browser-verified in Chrome (detection, blur, and the banner on live YouTube).

## Scope and limits
- Byte-scan presence detection, not signature validation (the full c2pa WASM SDK view is a later step).
- Streamed/blob media (e.g. a YouTube player stream) cannot be byte-read; on YouTube the AI signal comes
  from the page's disclosure label, not the stream. Platforms that re-encode strip the C2PA manifest.
- The rest of the v1.5.0 line (Backfire register / multi-band / content-bind, native-resolution video
  keying, and so on) is deliberately NOT in this patch.

## Release mechanics
- Source-only: no compiled artifact changes, so no paid matrix is required. The binaries remain the
  v1.4.0 build, and the tag marks "v1.4.0 plus the browser extension." Bump the workspace version and
  rebuild only if a fresh binary set is wanted.
- Public-safe: Apache-2.0 utility, no crown-jewel method, no adversary name, no held feature.

# v1.2.0 — feature-complete declaration

**A provcheck maintenance update, and the launch of Backfire.**

This release folds the maintenance and hardening work since v1.1.0 into one line, and
introduces Backfire, an experimental keyed image watermark. The provcheck verifier core
stays Apache-2.0 and unchanged in its guarantees; the new frontier tools are opt-in and
never bundled into the shipped binary.

## Headline: Backfire (new, experimental)

Backfire is an imperceptible, keyed image watermark that AI provenance-stripping attacks
**amplify instead of remove**. Instead of hiding a mark where a diffusion "purifier" deletes
it, Backfire optimizes the mark to be a fixed point of that purifier, so running the attack
makes the keyed identifier read *stronger*.

- **Standalone and AGPL.** Lives in `backfire/`, dual-licensed AGPL-3.0-or-later or
  commercial. It is a separate Python tool, never compiled into or linked with the
  Apache-2.0 provcheck binary.
- **Validated at 512 px** on 24 diverse COCO photos: survives a real diffusion purifier
  24 of 24 and a held-out purifier 24 of 24, amplifies on 21 of 24, at 34 dB. Zero false
  positives over 1,000 unmarked images. The `read` path is numpy-only and reproduces every
  claim; see `backfire/repro/`.
- **Honest by construction.** Ships its own `LIMITS.md` and a self-red-team: it discloses
  that an aggressive band-notch strips the mark, and answers it with a tamper tripwire (no
  notch both strips and evades detection across an 81-config grid). It is not crop-invariant.
- **Integrated as an experimental option.** The `provcheck` CLI gains `--backfire-read`, and
  the desktop app gains an experimental Backfire verify tab. Both shell out to the standalone
  tool and require the user's key.

## provcheck-mellin relicensed

The opt-in Fourier-Mellin audio watermark channel (`crates/provcheck-mellin/`) moves from
BUSL-1.1 to the same **AGPL-3.0-or-later OR commercial** dual license as Backfire, so the
two frontier tools share one licensing model. It remains opt-in and is never bundled into
the release binary.

## provcheck core maintenance

- Image verification degrades to a clean error instead of hard-crashing when the ONNX
  Runtime is missing or the wrong version.
- Dependency, security-advisory, and CI-gate hardening; a robustness matrix measuring
  detection survival against provenance strippers.

## Release readiness

The Backfire method is validated at research scale (numbers above), its tests pass, and the
provcheck workspace passes the pre-push gate. This file is the operator's affirmative
declaration that the codebase is feature-complete for the v1.2.0 line; the iterations that
constitute its scope are the commits from v1.1.0 to this tag.
